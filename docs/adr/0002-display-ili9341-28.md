# 0002. Use a 2.8" ILI9341 TFT for v1; OLED as an optional upgrade

- **Status:** Superseded by [0010](0010-display-ssd1351-oled.md) (2026-11-15): v1 uses a 1.5" SSD1351 OLED for true black.
- **Date:** 2026-11-14

## Context

In a Pepper's Ghost box the floating image is exactly as big as the screen, so the screen size *is* the size of the tank. Three other things matter:

1. **Black level.** An LCD backlight leaks light, so "black" pixels glow faintly and show up as a gray rectangle in the reflection. OLED pixels switch fully off.
2. **Brightness.** The reflector sends only a small fraction of the light to the viewer (about 4–10% for plain glass or plastic), so a dim screen gives a faint ghost.
3. **Simulator parity.** Wokwi simulates the ILI9341 directly. Matching the real panel to the simulator removes a porting step.

The original pitch picked a 2.0" ST7789 (320×240). A 2" ghost is small inside a desk-sized box.

## Decision

Use a **2.8" 320×240 ILI9341 SPI TFT** for v1.

- It's the same controller and resolution as the Wokwi simulator, so the firmware runs unchanged.
- It's about 40% wider than a 2.0" panel, which gives a noticeably bigger ghost at a similar price.
- The black-level leak is handled in the design: pure black background, matte black box interior, a dim room for the demo.

## Alternatives considered

| Option | Why not |
|---|---|
| 2.0" ST7789 IPS (original pitch) | The ghost is small. Different controller from the simulator, so the driver and init code must change. |
| 3.5" ST7796 (480×320) | Bigger ghost, but 2.25× the pixels for the same SPI bandwidth halves the full-frame rate. Keep it in mind for v2 if 2.8" feels small. |
| 1.5" SSD1351 OLED | True blacks give the cleanest ghost, but the image is tiny, it costs about $37–40, and it needs burn-in protection. Kept as an **optional upgrade**. |

## Consequences

- The firmware targets ILI9341 for both the simulator and the hardware. The display config is isolated in `src/display/lgfx_config.h`, so moving to ST7789, ST7796 or OLED later means changing one file.
- The faint backlight glow is an accepted limitation of v1.
- If the optics test shows the 2.8" ghost is too small or too dim, write a new ADR before ordering parts.
